# SmartHire

SmartHire is a resume and job matching application.

## Technologies

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- Python
- FastAPI
- REST APIs

## Project Architecture

Frontend → Java REST API → Python Analysis API

## Features

- Resume information input
- Job description input
- Skill matching
- Match percentage
- Missing skill detection
- Job application tracking
- REST API communication
